# vuln-manager

Gestión y priorización de vulnerabilidades a partir de SBOM CycloneDX. Cruza OSV.dev, el catálogo KEV y los datos SSVC de CISA y EPSS de FIRST, y prioriza por explotación real, exposición del servicio y parche disponible, con plazos de remediación según la BOD 26-04 de CISA.

> Estado: diseño (día 1). Consulta la [investigación y fuentes](docs/investigacion.md) y el [modelo de datos](docs/modelo-datos.md).
